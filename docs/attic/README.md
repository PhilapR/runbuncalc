# The attic

to mislead. Nothing here is deleted — a fossil is still a record of what the
project believed at the time — but nothing here should be TRUSTED either.

What replaced them:

- **The ordered work and its bars** — `docs/PLAN.md`, chosen from the stage map in `docs/WORKFLOW.md`
- **Current capabilities** — `INVENTORY.md` (generated from the code, drift-gated)
- **Standing rulings and open questions** — `DECISIONS.json` (rendered in INVENTORY.md, enforcement-gated)
- **What we know about the game and how** — the provenance registry in
  `profiles/run-and-bun/index.js` (rendered in INVENTORY.md, ratcheted)
- **Prior art in sibling repos** — `ECOSYSTEM.json` (path-verified)
